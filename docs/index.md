# Welcome to the SkyHigh Wiki

> The official documentation library for the SkyHigh aviation simulation network.

SkyHigh is an online aviation simulation network providing AI and virtual ATC services alongside a live pilot network. Whether you're a pilot looking to connect for the first time, an air traffic controller building a roster, or a staff member managing network operations — this wiki is your reference.
